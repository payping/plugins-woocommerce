افزونه درگاه پرداخت پی‌پینگ برای ووکامرس

== Description ==
با استفاده از این افزونه فروشگاه خود را به درگاه آنلاین پرداخت بانکی متصل کنید.

=== هوک‌ها برای توسعه‌دهندگان ===

می‌توانید با هوک‌های زیر رفتار درگاه را تغییر دهید یا رویدادهای پرداخت را دریافت کنید. پس از پرداخت موفق، هوک‌های استاندارد ووکامرس (مانند `woocommerce_payment_complete`) نیز به شکل معمول اجرا می‌شوند.

اکشن‌ها:

* `woo_payping_Payment_Success` — پس از تایید موفق پرداخت. پارامترها: `$order_id`, `$transaction_id`
* `woo_payping_Payment_Failed` — پس از تایید ناموفق پرداخت. پارامترها: `$order_id`, `$transaction_id`, `$message`
* `woo_payping_Payment_Duplicate` — هنگامی که پرداخت قبلا تایید شده باشد. پارامترها: `$order_id`, `$transaction_id`
* `woo_payping_Payment_Cancelled` — هنگام انصراف کاربر در صفحه بانک. پارامترها: `$order_id`
* `woo_payping_Send_to_Gateway_Failed` — هنگام خطا در ارسال سفارش به درگاه. پارامترها: `$order_id`, `$message`

فیلترها:

* `WC_payping_Gateway_Payment_api_url` — آدرس API ساخت پرداخت
* `WC_payping_Gateway_Payment_api_args` — آرگومان‌های کامل درخواست ساخت پرداخت (شامل بدنه درخواست)
* `WC_payping_Gateway_Payment_verify_api_url` — آدرس API تایید پرداخت
* `WC_payping_return_refid` — کد پیگیری بازگشتی از درگاه
* `WC_payping_Currency` — واحد پول مورد استفاده در محاسبه مبلغ
* `WC_payping_Description`، `WC_payping_Mobile`، `WC_payping_Email`، `WC_payping_Paymenter` — اطلاعات پرداخت‌کننده ارسالی به درگاه
* `woocommerce_order_amount_total_payping_gateway` و `woocommerce_order_amount_total_IRANIAN_gateways_before_check_currency`، `..._after_check_currency`، `..._irt` — تغییر مبلغ نهایی پرداخت
* `woo_payping_logo` — آدرس لوگوی درگاه
* `woo_payping_order_panel_rows` — ردیف‌های نمایش داده شده در بخش «داده‌های درگاه پی‌پینگ» در صفحه سفارش
* `WC_payping_Config` — فیلدهای تنظیمات درگاه

نمونه استفاده:

    add_action( 'woo_payping_Payment_Success', 'my_payping_sync', 10, 2 );
    function my_payping_sync( $order_id, $transaction_id ) {
        // کد شما
    }

== Installation ==
1. پوشه 'woo-payping-gateway' را در مسیر '/wp-content/plugins/' آپلود کنید
2. افزونه را از طریق منوی 'افزونه ها' در وردپرس فعال کنید
3. تنظیمات افزونه را می توانید از طریق قسمت تنظیمات ووکامرس / پیکربندی/ درگاه های پرداخت انجام دهید

== Frequently Asked Questions ==

= توکن درگاه پی‌پینگ را از کجا دریافت کنم؟ =

پس از ثبت‌نام در پی‌پینگ، از داشبورد شخصی به بخش «درگاه پرداخت» بروید و با گزینه «ایجاد» یک توکن بسازید. توکن دریافتی را در فیلد توکن تنظیمات افزونه وارد کنید. هنگام ساخت توکن به تاریخ انقضا، آدرس وب‌سایت و دسترسی‌های فعال شده دقت کنید.

= پیش‌نیاز نصب افزونه چیست؟ =

وردپرس و ووکامرس (و در صورت استفاده، ووکامرس فارسی) را به جدیدترین نسخه بروزرسانی کنید. همچنین پیش از نصب، از نصب نبودن نسخه دیگری از افزونه پرداخت پی‌پینگ برای ووکامرس اطمینان حاصل کنید.

= تنظیمات درگاه پی‌پینگ کجاست؟ =

از پیشخوان وردپرس به مسیر ووکامرس، پیکربندی، درگاه‌های پرداخت و سپس پی‌پینگ بروید و توکن و سایر تنظیمات درگاه را در همین صفحه وارد کنید.

= هنگام مواجهه با خطای 401 در اتصال به درگاه چه باید کرد؟ =

این خطا معمولا به دلیل منقضی شدن توکن یا عدم تطابق آدرس وب‌سایت و دسترسی‌های توکن با سایت شما رخ می‌دهد. توکن را در پنل پی‌پینگ ویرایش و «تعویض توکن» را انجام دهید، سپس توکن جدید را در تنظیمات درگاه جایگزین کنید.

= چه واحد پول‌هایی پشتیبانی می‌شود؟ =

ریال، تومان، هزار ریال و هزار تومان پشتیبانی می‌شوند. مبلغ سفارش در زمان ارسال به درگاه بر اساس واحد پول فروشگاه به تومان تبدیل می‌شود.

= آیا صفحه تسویه حساب بلوکی ووکامرس پشتیبانی می‌شود؟ =

بله. افزونه با Checkout Blocks ووکامرس سازگار است و درگاه پی‌پینگ به صورت خودکار در صفحه تسویه حساب بلوکی نیز نمایش داده می‌شود.

== Third-Party Services ==
This plugin leverages the following third-party services:

1. https://api.payping.ir: This plugin adds online payment functionality to the Woocommerce plugin, allowing us to process payments and check payment statuses through https://api.payping.ir.

This plugin follows strict privacy guidelines. When using the api.payping.ir service, user data is securely transmitted and stored following industry best practices.
